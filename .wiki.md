# Project Summary

Paper Reproduction Agent is a research tool for examining and reproducing machine-learning results reported in academic papers. It helps researchers review experiment records, evidence, and paper claims, with a frontend for browsing demo runs and a reproduction interface backed by Supabase components.

The frontend includes static recorded-run replay assets and a public reproduction app. Supabase schema and an Edge Function for running steps are also present. The supplied changes do not establish whether the reproduction app is connected to that function. The original Python agent and runner remain available as reference code.

# Project Module Description

- **Demo dashboard:** Browse supplied papers and recorded runs.
- **Run viewer:** Review recorded events by stage or timeline, including claims, requirements, assumptions, verdicts, and evidence.
- **Reproduction interface:** Public app assets provide the reproduction UI, directory and group data, localization, and a kit protocol.
- **Supabase run steps:** Edge Function and prompts support step-based reproduction workflows; consult the Supabase README for setup and operation.
- **Paper and evidence viewer:** Open associated PDFs and access event logs and evidence downloads.
- **Blog:** Render blog indexes and articles from configured routes.
- **Authentication routes:** Provide callback and error pages.
- **Reference agent:** Preserved Python modules cover paper processing, search, execution, sandbox, events, and server functionality; they are separate from the frontend replay flow.

# Technology Stack

- **Frontend:** React, TypeScript, Vite
- **Styling and UI:** Tailwind CSS and reusable component library
- **Reproduction interface:** Browser-based JavaScript, HTML, and CSS assets
- **Backend additions:** Supabase schema and Edge Function
- **Content:** Markdown blog rendering and prerendering utilities
- **Reference backend:** Python agent and sandbox runner from the preserved source
- **Run data:** Static JSON metadata, JSONL event recordings, and PDF documents

# Usage

From `app/frontend/`, install dependencies and start the frontend:

```bash
npm install
npm run dev
```

To check and build the frontend:

```bash
npm run lint
npm run build
```

The production build is written to `app/frontend/dist/`. Supplied recorded runs can be viewed without starting the Python backend.

For Supabase setup and operation, follow `supabase/README.md`; the schema is in `supabase/schema.sql` and the run-steps function is in `supabase/functions/run-steps/`. Running the preserved Python reproduction agent requires its own setup, documented in `uploads/reference/paper-repro-agent-main/README.md`.
