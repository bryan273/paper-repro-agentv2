# Project Summary

Paper Reproduction Agent is a research tool for inspecting and reproducing machine-learning results reported in academic papers. The current frontend lets users browse supplied demo experiments, review recorded run timelines, and inspect associated papers and evidence.

The frontend provides recorded replays only; it does not run new reproductions or connect to a live AI or sandbox backend. The original Python agent and runner remain as reference code.

# Project Module Description

- **Demo dashboard:** Browse demo papers and recorded runs.
- **Run viewer:** Navigate recorded events by stage or timeline and inspect claims, requirements, assumptions, verdicts, and audit evidence.
- **Paper viewer:** View associated PDFs and access event logs and evidence downloads.
- **Blog:** Render blog indexes and articles from configured routes.
- **Authentication routes:** Provide callback and error pages.
- **UI components:** Shared interface components, layout, and mobile and notification hooks.
- **Reference agent:** Preserved Python modules for paper processing, search, execution, sandboxing, events, and server functions. These are not connected to the frontend for live runs.

# Technology Stack

- **Frontend:** React, TypeScript, Vite
- **Styling and UI:** Tailwind CSS and reusable component library
- **Content:** Markdown blog rendering and prerendering utilities
- **Reference backend:** Python agent and sandbox runner from the uploaded source
- **Run data:** Static JSON metadata, recorded event data, and PDF documents

# Usage

From `app/frontend/`:

```bash
npm install
npm run dev
```

To check and build the frontend:

```bash
npm run lint
npm run build
```

The production build is written to `app/frontend/dist/`. Supplied runs can be viewed without starting the Python backend. Running new reproductions requires the original sandbox runner and backend setup, which are not connected to this frontend.
