# Project Summary

Paper Reproduction Agent helps researchers assess and reproduce machine-learning results reported in academic papers. Its dashboard and static viewers let users explore recorded experiments, inspect claims and evidence, and browse benchmark runs without requiring a live reproduction backend.

The project now also includes a Python reproduction and benchmarking toolkit, structured benchmark datasets, and an explainer-video pipeline for turning selected papers into renderable scripts and reports. Supplied recordings and benchmark artifacts support reproducible review, while Docker and Supabase components provide deployment and service integrations.

# Project Module Description

- **Demo dashboard and run viewer:** Browse demo papers and recorded runs; inspect event timelines, stages, claims, assumptions, verdicts, and evidence.
- **Reproduction and benchmark UI:** View recorded reproduction and benchmark data, with navigation, localization, and bundled fonts.
- **Python reproduction agent:** Process papers, search for sources, plan and execute runs, record events, and support sandboxed execution.
- **Benchmark workflow:** Discover and triage candidate papers, freeze paper plans and claim contracts, run reader and injection evaluations, and export or score results.
- **Explainer pipeline:** Prepare paper scripts and scene prompts, manage render jobs, build reports and player bundles, and generate supporting social and vertical-video assets.
- **Supabase integrations:** Provide run-step and agent LLM functions, explainer-render job handling, and database schemas.
- **Web content and shared UI:** Render blog pages, authentication routes, reusable interface components, and prerendered routes.
- **Reference materials:** Preserve the original Python agent, web UI, tests, operational scripts, and project documentation.

# Technology Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Static reproduction UI:** HTML, JavaScript, CSS, localized strings, bundled fonts
- **Agent and benchmarks:** Python
- **Explainer tooling:** Python scripts, JSON script bundles, and HTML player assets
- **Backend services:** Supabase Edge Functions and SQL
- **Data formats:** JSON, JSONL, Markdown, and PDF
- **Deployment and automation:** Docker, Docker Compose, and GitHub Actions

# Usage

For the frontend, from `app/frontend/`:

```bash
npm install
npm run dev
```

Check and build the frontend:

```bash
npm run lint
npm run build
```

The production frontend build is written to `app/frontend/dist/`.

For the Python toolkit, from the project root:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

On Windows, activate the virtual environment with `.venv\Scripts\activate`. Configure environment variables using `.env.example`. Use the project README and script help for the specific agent, benchmark, and explainer workflows.

To build and run the container deployment, use the Dockerfile and `deploy/docker-compose.yml`. Recorded demos and benchmark runs can be inspected without starting the Python backend.
