# Project Summary

Paper Reproduction Agent is a research tool for inspecting and reproducing machine-learning results reported in academic papers. This repository provides a web frontend for reviewing supplied demo experiments: users can browse recorded runs, follow their event timelines, and inspect associated papers and evidence.

The frontend currently provides **recorded replays only**. It does not run new reproductions or connect to a live AI or sandbox backend. The original Python agent and runner are preserved as reference code.

# Project Module Description

- **Demo dashboard:** Browse the supplied demo papers and recorded runs.
- **Run viewer:** Navigate recorded events by stage or timeline and inspect claims, requirements, assumptions, verdicts, and audit evidence.
- **Paper viewer:** Open associated PDFs and access the original event logs and evidence downloads.
- **Blog:** Render blog indexes and articles from configured routes.
- **Authentication routes:** Provide callback and error pages.
- **UI components:** Shared interface controls, layout elements, and mobile and notification hooks.
- **Reference agent:** The preserved Python project contains paper processing, search, execution, sandbox, event, and server modules. It is not connected to the frontend for live runs.

# Technology Stack

- **Frontend:** React, TypeScript, Vite
- **Styling and UI:** Tailwind CSS and reusable component library
- **Content:** Markdown blog rendering and prerendering utilities
- **Reference backend:** Python agent and sandbox runner from the uploaded source
- **Run data:** Static JSON metadata, JSONL event recordings, and PDF documents

# Usage

From `app/frontend/`:

```bash
npm install
npm run dev
```

To check and build the frontend:

```bash
npm run lint
npm run build
```

The production build is written to `app/frontend/dist/`. The supplied runs can be viewed without starting the Python backend. Running new reproductions requires the original sandbox runner and backend setup; that functionality is not connected to this frontend.
