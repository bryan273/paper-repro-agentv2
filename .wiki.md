# Project Summary

Paper Reproduction Agent helps researchers inspect and reproduce machine-learning results reported in academic papers. The frontend presents demo papers, recorded experiment runs, and evidence so users can review claims, assumptions, verdicts, and event timelines without needing a live reproduction backend.

The project also includes a reproduction interface, a benchmark viewer with recorded runs, fitting and compute-related utilities, blog content, localization, Supabase support, and preserved Python agent and runner reference code.

# Project Module Description

- **Demo dashboard:** Browse demo papers and their recorded runs.
- **Run viewer:** Review recorded events by stage or timeline, including claims, requirements, assumptions, verdicts, and evidence.
- **Reproduction UI:** Provide a localized reproduction interface with job-related UI logic.
- **Benchmark viewer:** Display benchmark metadata and a collection of recorded JSONL runs.
- **Fit and compute utilities:** Provide fitting and fit-box UI logic, alongside compute metadata.
- **Run-steps function:** Supabase Edge Function and prompts for run-step processing.
- **Paper viewer:** Open associated PDFs and access event logs and evidence downloads.
- **Blog:** Render blog indexes and articles from configured routes.
- **Authentication routes:** Provide callback and error pages.
- **Shared UI:** Reusable components, layouts, and mobile and notification hooks.
- **Reference agent:** Preserved Python modules for paper processing, search, execution, sandboxing, events, and server functionality.

# Technology Stack

- **Frontend:** React, TypeScript, Vite
- **Styling and UI:** Tailwind CSS and reusable component library
- **Content:** Markdown blog rendering and prerendering utilities
- **Reproduction and benchmark interfaces:** HTML, JavaScript, and CSS
- **Localization:** JavaScript localization support for the reproduction UI
- **Backend:** Supabase Edge Function and SQL schema
- **Reference backend and utilities:** Preserved Python agent, sandbox runner, and probe utility
- **Run data:** Static JSON metadata, JSONL event recordings, and PDF documents

# Usage

From `app/frontend/`, install dependencies and start the frontend:

```bash
npm install
npm run dev
```

Run checks and create a production build:

```bash
npm run lint
npm run build
```

The production build is written to `app/frontend/dist/`. The reproduction and benchmark interfaces and supplied run recordings are included as static assets; recorded runs can be inspected without starting the Python backend.
